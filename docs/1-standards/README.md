## What was loaded for this project

Standards are loaded on demand based on the detected tech stack.
Only the files relevant to this project were fetched.

| File | Loaded | Applies when |
|---|---|---|
| `universal/never-do.md` | ✅ | Always |
| `universal/ask-first.md` | ✅ | Always |
| `universal/always-do.md` | ✅ | Always |
| `react/react-core.md` | ✅ | Any React component |
| `react/nextjs-conventions.md` | ✅ | Next.js pages and routing |
| `react/typescript-conventions.md` | ✅ | TypeScript usage |
| `react/testing-standards.md` | ✅ | Writing or modifying tests |
